# Shortcuts

## Global shortcuts

They work in any app. Source: `Quicknote/App/Shortcuts.swift`.

| Shortcut | Does | Page |
|---|---|---|
| `⌃⌥N` | New note | [capture](features/capture.md) |
| `⌃⌥K` | Hold to talk: hold, speak, release | [voice](features/voice.md) |
| `⌃⌥4` | Snap | [snap](features/snap.md) |
| `⌃⌥C` | New card | [cards](features/cards.md) |
| `⌃⌥F` | Search | [search](features/search-and-export.md) |
| `⌃⌥S` | Save where I stopped | [capture](features/capture.md) |
| `⌃⌥B` | Bookmark meeting moment. Does nothing when no meeting is recording | [meetings](features/meetings.md) |

Starting and stopping a meeting recording has no shortcut; use the menu.

## Change a shortcut

1. Menu bar icon › Settings… (`⌘,`) › Shortcuts.
2. Click a recorder and press the new keys. Quicknote warns when the keys are taken.
3. **Restore defaults** resets all seven.

The welcome window's **Change shortcuts** button opens the same tab.

## Menu bar menu

| Key | Does |
|---|---|
| `⌘,` | Settings |
| `⌘Q` | Quit Quicknote |

The global shortcuts are shown beside their menu items.

## Capture panel and Save where I stopped

| Key | Does |
|---|---|
| `↵` | Save. In Save where I stopped, `↵` in any field saves |
| `⇧↵` | New line |
| `⇥` | Next note type |
| `Esc` | Close and keep the draft |

## Search panel

| Key | Does |
|---|---|
| `↑` `↓` | Move through all results; stops at the first and last |
| `↵` or click | Open the result |
| `⌘↵` | Show the Library |
| `Esc` | Close |
| `⌃⌥F` while open | Select the text in the field |

## Library

| Key | Does |
|---|---|
| Arrow keys | Move in the sidebar and lists |
| `⇧`-arrow, `⌘`-click | Select several notes |
| `⌫` | Delete the selection, after a confirmation |
| `⌘F` | Open search |

## Editor

| Key | Does |
|---|---|
| `*bold*`, `_italic_` | Bold and italic |
| `- ` at line start | List item |
| `[] ` at line start | Checkbox. Click it to tick |
| `[[` | Link to another note: `↑` `↓` choose, `↵` picks, `Esc` closes |

## Edge tabs

| Key | Does |
|---|---|
| `Space` on a focused tab | Open the card |
| `Esc` | Close the card |

## Snap editor

Press the key while the canvas has focus. Keys do not fire while you type a caption.

| Key | Tool |
|---|---|
| `V` | Select |
| `A` | Arrow |
| `L` | Line |
| `B` | Box |
| `D` | Diamond |
| `C` | Circle |
| `G` | Triangle |
| `T` | Text (`↵` to finish) |
| `S` | Step |
| `H` | Highlight |
| `U` | Blur |

| Key | Does |
|---|---|
| `⌫` | Delete the selection |
| Arrow keys | Nudge 1 px; with `⇧`, 10 px |
| `↵` | Edit selected text |
| `⌘Z`, `⇧⌘Z` | Undo, redo |
| `Esc` in the selection overlay | Cancel the Snap |

## Dialogs

`↵` presses the main button and `Esc` presses Cancel in the "Add to Calendar?" panel, the permission explainer, the Start meeting recording sheet and the Delete everything confirmation.
